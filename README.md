# ParkEngine – Scalable Parking Allocation System

## About the Project

ParkEngine is a Java-based parking lot management system designed to manage vehicle parking, parking spot allocation, ticket generation, and payment processing.

## Features

* Supports bikes, cars, and trucks.
* Manages multiple parking floors and parking spots.
* Generates parking tickets.
* Calculates parking charges.
* Supports cash, card, and UPI payment options.
* Displays parking spot availability.

## Technologies Used

* Java
* Object-Oriented Programming (OOP)
* Java Collections
* Design Patterns

## Design Patterns

* **Singleton Pattern:** Manages the parking lot instance.
* **Factory Pattern:** Helps create objects.
* **Observer Pattern:** Updates the parking display board.
* **Strategy Pattern:** Supports different parking and payment strategies.

## How to Run

### Requirements

* Java Development Kit (JDK)

### Compile

```bash
javac -d out src/ParkEngine.java
```

### Run

```bash
java -cp out ParkEngine
```
